В рамках проекта была решена задача бинарной классификации — прогнозирование задержки авиарейсов на основе табличных данных. Целью являлось выявление факторов, влияющих на вероятность задержки рейса, а также сравнение качества различных моделей машинного обучения. Проект охватывает полный ML-пайплайн: от исследовательского анализа данных и предобработки признаков до обучения моделей, оценки качества и интерпретации результатов.
Используется датасет с информацией об авиарейсах, включающий более 500 000 наблюдений. В данных представлены как числовые, так и категориальные признаки.
Проведен исследовательский анализ данных (EDA), подготовка данных, разделение признаков на числовые и категориальные, One-Hot Encoding категориальных признаков, масштабирование числовых признаков.
Обучаются модели: Logistic Regression (baseline) и Random Forest Classifier
Используемые технологии: Python, Pandas, NumPy, Matplotlib, Scikit-learn

Результаты
Модель	Accuracy	Precision	Recall	F1-score	ROC-AUC
Logistic Regression	~0.64	~0.59	~0.58	~0.59	~0.69
Random Forest	~0.64	~0.61	~0.54	~0.58	~0.70

Модель Random Forest показала немного более высокое значение ROC-AUC, в то время как логистическая регрессия демонстрирует более интерпретируемое и стабильное поведение. Оба подхода позволяют выявить ключевые факторы, влияющие на задержки рейсов.

Датасет: https://www.kaggle.com/datasets/ulrikthygepedersen/airlines-delay
